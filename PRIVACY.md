# Privacy Policy

Last updated: October 14, 2026

This privacy policy explains how data is handled in **Project OLDR**.

## 1. Data Collected
To provide account creation and authentication, the application only processes:
* **Username:** Chosen by the user.
* **Password:** Securely hashed before being stored in the database. 

We do **not** collect or store email addresses, real names, or IP addresses.

## 2. Data Usage
The collected data is used exclusively for account authentication and enabling core application features (such as friends list and login).

## 3. Data Security
* Passwords are securely hashed using standard cryptographic protocols.
* Data is stored securely via Supabase.
* We never sell, rent, or share any data with third parties.

## 4. User Rights
Since we do not collect personal identifying information (like emails or real names), accounts and associated data can be deleted upon request by opening an issue on this repository.
